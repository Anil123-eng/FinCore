# Assessment 1: Financial Customer Frontend

## Overview
Implement the required customer and operations interfaces for the FinCore platform, including wallets, beneficiaries, transfers, transaction history, disputes and reports.

## Handbook Requirements
- Assessment 1 from FinCore Handbook Section 6
- Implement the required customer and operations interfaces

## Technology Stack
- React
- Next.js App Router
- TypeScript
- Tailwind CSS or Material UI
- TanStack Query and/or Redux Toolkit where required
- Suitable schema-based form validation

## Implementation Details
- Customer profiles
- Wallets/accounts
- Beneficiaries
- Double-entry ledger
- Transfers
- Payment intents
- Refunds and reversals
- Disputes
- Reconciliation
- Risk alerts
- Statements
- Audit trail

## Important Rules
- Use synthetic financial data and simulated transactions only
- Never process real money or use real banking credentials
- Clearly identify simulated integrations and unavoidable limitations

## Files to be Created
- frontend/src/app/page.tsx
- frontend/src/app/layout.tsx
- frontend/src/app/globals.css
- frontend/package.json

## Implementation Notes
- Use schema-based form validation
- Use responsive layouts
- Include loading, empty and error states
- Implement responsive layouts
