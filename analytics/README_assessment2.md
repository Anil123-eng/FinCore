# Assessment 2: Financial REST APIs

## Overview
Implement the required REST APIs for the FinCore platform, including customers, accounts, wallets, beneficiaries, transfers, payment intents, refunds, reversals, disputes and statements.

## Handbook Requirements
- Assessment 2 from FinCore Handbook Section 6
- Implement the required customer, account, wallet, beneficiary, transfer, payment intent, refund, reversal, dispute and statement APIs

## Technology Stack
- Node.js
- Express.js
- REST APIs
- PostgreSQL database
- PostgreSQL migrations using Drizzle ORM or Prisma
- TypeScript type safety

## Implementation Details
- Customer API endpoints
- Account API endpoints
- Wallet API endpoints
- Beneficiary API endpoints
- Transfer API endpoints
- Payment intent API endpoints
- Refund and reversal API endpoints
- Dispute API endpoints
- Statement API endpoints

## Important Files
- backend/src/app.ts
- backend/package.json
- backend/tsconfig.json
- backend/src/api/routes/

## Running the Implementation
```bash
cd backend
npm install
npm run build
npm run dev
```

## Verification Commands
- `npm run build`
