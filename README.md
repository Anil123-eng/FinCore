# FinCore

Digital Wallet, Ledger & Payment Processing Platform

## Project Overview

FinCore is a simulated digital finance platform where customers can create wallets, manage beneficiaries, transfer simulated funds, review statements, and raise disputes.

Operations staff can investigate suspicious activity and reconcile payment-provider events.

## Technology Stack

- Frontend: React, Next.js, TypeScript
- Backend: Node.js, Express.js
- Analytics: Python, FastAPI
- Database: PostgreSQL
- Caching and Jobs: Redis
- Testing: Jest, Playwright, pytest
- DevOps: Git, GitHub, Docker, GitHub Actions

## Project Structure

- frontend: Customer and operations interface
- backend: REST API and business logic
- analytics: Python analytics service
- database: Migrations and seed data
- docs: Project documentation
- infrastructure: Docker configuration
- tests: Automated tests

## Important Notice

This is an educational simulation. No real funds or banking credentials are used.
